### 从数学角度来看

一层的递归就是一次遍历

递归

1. 确立终止条件
2. 参数和返回值
3. 主体逻辑


回溯法的本质就是**深度优先搜索（DFS）** 在一棵决策树上的遍历。

- 每一层递归 = 做一次决策（选还是不选？选哪个？）
- 递归到底 = 到达决策树的叶子 = 一个完整解
- 回溯 = 撤销上一步的选择，尝试下一个选项

经典的解题模板：

```
def backtrack(路径, 选择列表):
    if 满足终止条件:
        收集结果
        return
    for 选择 in 选择列表:
        做选择      # 把选择加入路径
        backtrack(路径, 新的选择列表)
        撤销选择    # 回溯：把之前的操作撤销
```

### 实战：力扣 77 组合问题

> 给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。

先画决策树（n=4, k=2）：

```
                     []
        ┌──────┬──────┬──────┐
       [1]    [2]    [3]    [4]
      /  \    /  \     |
   [1,2] [1,3] [2,3] [3,4]
    ...    [1,4] [2,4]
```

从树上看，组合数 = 叶子节点的数量。代码实现：

```python
def combine(n, k):
    res = []
    path = []

    def backtrack(start):
        if len(path) == k:          # 终止条件：凑够 k 个数
            res.append(path[:])     # 收集结果
            return
        for i in range(start, n + 1):
            path.append(i)          # 做选择
            backtrack(i + 1)        # 递归（从 i+1 开始，去重）
            path.pop()              # 回溯：撤销选择

    backtrack(1)
    return res

# combine(4, 2) → [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

### 回溯 vs 纯递归

| 普通递归 | 回溯 |
|---------|------|
| 一条路走到底，返回汇总结果 | 走到底，撤销，换条路再走 |
| 类似"分而治之" | 类似"试错法" |
| 归并排序、快速排序 | 组合、排列、N皇后 |

## 总结

- 有组合、排列、子集问题的地方，就有回溯
- 三步搞定：**终止条件 → 遍历选择 → 做选择+递归+撤销**
- 画决策树是最高效的理解方式——树画出来了，代码就出来了
